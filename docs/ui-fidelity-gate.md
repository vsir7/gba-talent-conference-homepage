# UI 设计稿还原门禁

适用范围：所有由静态 UI 设计稿还原的 H5 页面。此门禁优先于“页面可打开”“构建通过”或“无控制台错误”。

## 放行条件

每页必须同时满足下列条件，才可标记为“完成”并进入下一组：

1. 已登记原始设计稿路径、SHA-256、像素尺寸、可见状态和目标路由。
2. 已明确渲染合同；若设计稿未提供 CSS 视口、DPR、字体及导出环境，视觉等级必须标为 `blocked`，不得声称逐像素通过。
3. 使用真实 DOM、语义控件及可追溯的本地素材；不得以整页截图、带文字的卡片裁片或占位/错位插画替代设计稿内容。
4. 完成全页人工视觉审查，逐项检查：页面壳、主视觉、素材角色、模块顺序、卡片几何、间距、字体层级、换行、颜色、圆角、阴影、固定区及底部收口。
5. 所有严重视觉缺陷均为零：错误主视觉、缺失/错误关键素材、错误模块结构、明显文字换行、模块重排、明显比例错误、横向溢出、资源失效、控制台错误均会阻断放行。
6. 在参考合同宽度完成至少三次独立 Chrome 稳定截图；候选图之间必须稳定。若可取得匹配合同和字体，额外执行严格像素差分门禁。
7. 375px 与 750px 进行独立响应式检查；750px 只能按设计扩展，不能用全局缩放或改变模块阅读顺序。
8. 生产构建、静态检查、相关测试及生产产物预览全部通过。

## 审查结果分类

- `pass`：上述条件均满足，并且视觉合同允许该等级的声明。
- `rework-required`：发现任一明显视觉差异；页面不得进入下一组验收。
- `blocked`：缺少参考合同、字体、素材或可复现环境；必须说明最小补充材料。
