# 页面管理看板设计

## 目标

为已开发的大会静态页面提供统一入口。用户可在一个看板中看到当前可预览页面，并通过左侧目录切换右侧的真实页面内容，无需依赖各页面内部导航。

## 范围

纳入四个页面：

1. `index.html`（大会首页）
2. `schedule.html`（大会日程）
3. `entry-service.html`（入场服务）
4. `profile.html`（个人中心）

不修改以上页面的业务内容、路由或既有交互；不新增后端、鉴权或远程数据加载。

## 信息架构与布局

- 新增 `page-board.html` 作为看板入口。
- 左侧为固定目录，包含页面名称、说明、选中状态和页面顺序。
- 右侧为预览工作区：顶部显示当前页面名称与画布规格，主体承载一个真实 `iframe`。
- `iframe` 仅加载相对路径的本地页面，并以 `750px` 宽画布居中预览；大于画布的外侧空间作为看板背景，小屏时预览区域允许安全的横向查看，不缩放页面。
- 看板本身采用大会既有浅色、淡紫背景、深紫标题和轻量卡片语义；不改变被预览页面的视觉系统。

## 交互与状态

- 目录使用原生按钮；点击后更新选中态、标题、`iframe.src` 和 URL 哈希（如 `#schedule`）。
- 浏览器刷新或前进/后退时，根据 URL 哈希恢复对应页面；非法哈希回退到首页。
- 提供“在新标签页打开”链接，指向当前预览页面。
- `iframe` 加载期间显示加载状态；加载成功后隐藏；加载失败时显示有意义的错误提示与重试按钮。
- 键盘可聚焦目录项，当前项有 `aria-current="page"`；不依赖鼠标 hover 才能完成操作。

## 文件与模块边界

- `page-board.html`：语义结构、目录、预览区、状态提示。
- `page-board.css`：看板布局、宽/窄屏响应式、焦点和减少动态效果支持。
- `page-board.js`：页面注册表、哈希路由、目录渲染、加载与错误状态管理。
- `tests/page-board.test.mjs`：生产文件、页面注册表、语义、750px 预览合同和安全交互的静态回归测试。
- `scripts/build.mjs` 和 `scripts/qa-static.mjs`：纳入生产构建与静态检查。

## 错误处理

- 页面注册表只接受预定义的相对路径，避免将 URL 哈希直接作为任意 `iframe` 地址。
- 找不到页面或 `iframe` 发生错误时，不清空目录；保留当前页面名称并给出重试操作。
- JavaScript 不可用时，页面目录中的普通链接仍可直接打开对应页面。

## 验收与验证

- 在 750px 视口：看板右侧预览的页面壳宽为 750px，无横向溢出。
- 在 1280px 桌面视口：左栏和预览工作区同时可用，预览保持 750px。
- 在窄视口：目录与预览区不遮挡核心内容，目录仍可切换页面。
- 目录切换、哈希恢复、加载状态、失败重试和新标签页链接均可用。
- 通过项目自动化测试、静态检查、生产构建，以及 Chrome 的真实浏览器检查；不以截图替代真实页面。
