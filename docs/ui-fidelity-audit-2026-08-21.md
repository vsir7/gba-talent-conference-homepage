## 放行前的共同前置条件

1. 由设计方确认每张原稿的 CSS 视口、DPR、截图范围（是否包含系统状态栏/Home Indicator）、字体文件与导出环境；随后为每个页面建立独立渲染合同。
2. 对每页先完成上述表中列出的关键视觉和几何返工；不得用整页/整卡截图替代 DOM。
3. 每页在登记合同下用全新 Chrome 进程串行截图至少三次，候选截图两两零差异后，再与未改动原稿做严格像素差分。
4. 只有严格差分为零、无资源/运行问题、375px 与 750px 响应式无模块重排/遮挡的页面，才可改为 `pass`。在此前，任何“百分之百还原”或“像素级通过”的说法均不成立。
