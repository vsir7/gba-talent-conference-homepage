## 1. 设计源与真实性

1. **设计源映射不完整**：未登记参考图、状态、路径和哈希；没有设计源却声称像素级还原。
2. **设计源优先级错误**：视觉源、产品文档、口头理解和现有页面冲突时未先对齐源头。
3. **参考图环境不明**：未确认压缩、缩放、DPR、浏览器壳、设备壳、状态栏和捕获方式。
4. **整图或复合裁图伪装**：把整页、卡片、按钮、表单、Tab 或含文字模块当图片使用。
5. **真实 DOM 缺失**：标题、金额、日期、状态、标签、按钮、表单、进度、Tab 和列表文案未用 DOM/CSS 渲染。
6. **静态图外推过度**：从单一状态擅自推断未展示页面、响应式规则、隐藏内容或完整业务流程。

## 2. 页面壳、导航与流程

7. **页面壳错误**：状态栏、安全区、刘海区、页面壳高度、底部 Home Indicator 不准。
8. **滚动容器错误**：外层/内层滚动混乱、页面滑不到底、PC 预览手机壳被裁切。
9. **固定区遮挡**：最后内容被底部 Tab、固定按钮、键盘或安全区覆盖。
10. **一级/二级页导航错误**：一级页误出现返回键，二级页缺返回键或行为不统一。
11. **顶部 Tab 不一致**：位置、尺寸、active 态、指示器和切换交互不统一。
12. **底部 Tab 不一致**：数量、高亮、图标、文字、点击区和安全区不正确。
13. **页面入口闭环缺失**：入口不可点、跳错页、返回路径不闭合或缺失页被静默忽略。
14. **目标截图状态错误**：捕获时的 Tab、弹层、表单值、滚动位置或数据与参考图不同。

## 3. 几何、排版与视觉 token

15. **对齐和基线错误**：图标、标题、输入提示、金额、数字、箭头、按钮、时间和状态不在同一轨道或基线。
16. **左右边界不齐**：卡片、标题、统计、筛选、列表文本和操作区的边界/中心线不一致。
17. **元素重叠**：按钮压文字，金额压标题，标签/角标压内容，图标压标题。
18. **文字溢出与异常换行**：长标题、企业名、人名、按钮、标签、链接、金额和日期显示不全。
19. **固定高度裁切**：卡片、表单、列表或统计模块的内容被固定高度裁掉。
20. **真实数据压力不足**：未测试最大金额、最长标题、最多标签、多行地址和长公司名。
21. **字体文件不精确**：使用替代字体、错误字重或字体 fallback，却仍声称 exact。
22. **字号/字重/行高错误**：标题层级、按钮垂直位置、多行中文行距或次级文字层级不准。
23. **随意切字体**：局部新增 `font-family` 掩盖布局或字重问题。
24. **字距和数字宽度错误**：letter-spacing、等宽数字、货币符号、百分比和日期指标不准。
25. **颜色不一致**：背景、主题色、状态色、文字色和透明度不匹配。
26. **阴影/边框/圆角不一致**：方向、模糊、扩散、描边宽度和圆角与参考图不符。
27. **间距和视觉密度错误**：模块间距忽大忽小，卡片过挤/过空，首屏露出内容数量不同。
28. **卡片内部比例错误**：图片区、文字区、金额区、状态区和操作区比例不对。
29. **全局缩放或错 DPR**：用 transform/zoom 强行塞入画布，或 CSS 视口、DPR、截图 scale 对应错误。

## 4. 素材与图标

30. **素材角色或策略错误**：未先区分金刚位、辅助小图标、品牌、内容图和主视觉；精确资产可用时无依据改用近似生成图，或使用未授权第三方素材。
31. **图片/封面缺失或低保真**：头像、Logo、封面、证书、插画和业务图仍是占位或空白。
32. **图片比例与裁切错误**：拉伸、主体偏移、白边/黑边、透明边缘、残影或 object-position 错误。
33. **列表封面与文本区不匹配**：封面宽高与相邻文本区比例不准，主体未填满容器。
34. **背景图尺寸错误**：背景/Banner/票券未覆盖容器，文字或按钮溢出背景。
35. **图标缺失、分类或语义错误**：金刚位与普通辅助小图标角色误判，或位置、业务语义、状态和流程图标缺失/替代错误。
36. **图标风格不统一**：生成金刚位的视角、材质、主体比例和光照漂移，或普通小图标混用不同线宽、圆角、填充、颜色、viewBox、emoji 和字符图标。
37. **图标基线和点击区错误**：图标未居中、与文字掉线或点击热区小于 44px。
38. **原子素材提取越界**：裁切包含 UI 文字、卡片背景、控件状态、多个图标或相邻结构，未保持单一原子资产。
39. **生成素材门禁缺失或冒充精确资产**：选择生成分支后未保存 prompt、源输出、后处理、哈希和一致性检查，或生成图未通过差分却被写成与参考图一致。
40. **资产授权或来源不可追溯**：普通第三方小图标/图片未确认许可、版本、本地路径或来源；生成素材未记录工具、prompt、哈希和参考权利。

## 5. 组件与交互

41. **标签/Chip 样式或布局错误**：颜色语义、圆角、padding、高度、line-height、数量和换行不准。
42. **按钮尺寸或状态缺失**：高度、宽度、字号、主次层级、active/disabled/loading/反馈不完整。
43. **点击热区和误触风险**：图标可见但不可点，整行视觉可点但只有文字可点，按钮间距过近。
44. **表单组件错误**：长文本不用 textarea，计数位置、滚动条、focus、placeholder 或错误态不准。
45. **搜索/筛选/排序错误**：高度、箭头、active 态、筛选反馈或批注要求删除的冗余控件不正确。
46. **进度/流程状态错误**：连接线、当前/完成节点、数字、箭头和步骤间距不统一。
47. **z-index/浮层问题**：Toast、弹窗、固定按钮、Tab、角标和卡片内容层级冲突。
48. **交互死页面**：Tab、轮播、筛选、表单、选中、展开、提交、返回和主要 CTA 没有基础可用交互。

## 6. 响应式、运行质量与证据

49. **响应式和运行证据缺失**：375/390/414 或项目目标宽度存在溢出、裁切、遮挡；图片 404、控制台报错、字体未加载、中文编码异常；未保存首屏/底部/长图、`.capture.json`、`diff.png`、`overlay.png`、`metrics.json` 和最终报告却声明完成。
50. **验收等级虚报**：尺寸不一致、存在非零像素差异、使用阈值/蒙版、只做人工目测或无法运行浏览器时，仍使用“100%”“完全一致”或“像素级通过”。

## 7. 使用方法

开发前建立页面矩阵：

| ID | 状态 | 参考证据 | 规避方案 | 实现结果 | 最终复核 |
| --- | --- | --- | --- | --- | --- |
| 1–50 | 涉及 / N/A / 待确认 | 文件、批注或规范 | 结构、字体、素材、交互或验证方案 | pending/pass/fail | pending/pass/fail |

执行规则：

1. 不允许跳过整类问题；不涉及时标记 N/A 并给出简短理由。
2. 先处理页面壳、滚动、固定区、主轨道、字体和精确资产等高风险项。
3. 每完成一个模块立即复核相关条目，不等整页结束后集中返工。
4. 最终 exact 门禁失败时，把对应问题重新标记为 fail，记录差异包围盒和下一步修复。
5. 任一涉及项没有规避方案、实现结果或复核证据时，不得声明页面完成。
